# go-utils
utils for golang

## 📦 Packages

### ✅ Response - REST API Response Pattern
Flexible and framework-agnostic REST API response patterns supporting multiple formats (Envelope, Flat, Lean, HAL, Validation) with i18n support.

[📖 Documentation](./response/README.md)

### ✅ Logger - Zap Logger Wrapper
A wrapper for uber-go/zap logger with structured logging.

[📖 Documentation](./logger/README.md)

### ✅ JSON - Multi-engine JSON Wrapper
A wrapper for encoding/json, sonic, jsoniter, and go-json with configurable engines.

[📖 Documentation](./json/README.md)

### ✅ Configs - Viper Configuration Wrapper
A wrapper for spf13/viper for configuration management.

### ✅ KeyFormatter - Key Beautifier
Utility for formatting and beautifying keys.

### ✅ XLS - Excel Utilities
Utilities for working with Excel files using excelize.

### ✅ Errors - Enhanced Error Handling
Enhanced error handling with stack traces.

### ✅ Generic - Generic Utilities
Common generic utility functions.
